# 🤖 InterviewAI - AI Powered Interview Preparation Assistant

## 📌 Project Overview

InterviewAI is a mini AI-based mock interview preparation system that helps students practice technical interviews and receive automated feedback.

The system analyzes candidate answers using Natural Language Processing (NLP) techniques and provides a performance score by comparing answers with expected model answers.

---

## 🎯 Objective

The main objective of InterviewAI is to provide an intelligent interview practice environment where candidates can:

- Practice technical interview questions
- Get instant AI-based evaluation
- Understand strengths and weaknesses
- Improve interview preparation

---

## ✨ Features

✅ AI-based interview answer evaluation  
✅ Semantic similarity analysis  
✅ Automated performance scoring  
✅ Candidate response comparison  
✅ Interview performance visualization
